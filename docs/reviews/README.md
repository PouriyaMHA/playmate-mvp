# Reviews

Codex reviews that Claude Code requests (`codex exec` / `codex review`), one file per round:
`<YYYY-MM-DD>-<topic>.md`. Claude answers each round in the same file under a `## Claude's response` heading
(fixed / disagree + why), so the back-and-forth stays in one place. Unresolved disagreements go to the owner.

Earlier, before this folder: `docs/CODEX_REVIEW.md` (first full review) and `docs/CODEX_FIX_REPORT.md` (what was fixed).
